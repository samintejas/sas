# Assets

- `dots/tokens.json`: the Dots design system tokens (colours, type, spacing,
  radii, sizes) copied from the design canvas. `sat-theme` generates its
  `Theme` from this file at build time, so the app and the prototype share one
  source of truth. Replace the file to update the theme.
- `fonts/`: Geist (labels) and Geist Mono (numbers), variable TTFs from
  Google Fonts, under the SIL Open Font License (`fonts/OFL.txt`).
